# MAGDA-MCP v0.1.0

发布日期：2026-10-15。正式支持 Windows x64、Node.js 24+、MAGDA 0.20.2。

本版提供 stdio → Streamable HTTP 网关，接入 154 个原生工具、8 个固定资源、4 个资源模板，并增加 magda_mcp.status 与 magda_mcp.reconnect。工具业务参数、Schema、结果、revision、幂等键和权限继续由 MAGDA 定义。

## 安装

下载本 Release 的 dionysusdwi-magda-mcp-0.1.0.tgz 和 SHA256SUMS。通过 Get-FileHash 核对 SHA-256 后运行：

~~~powershell
npm install --global .\dionysusdwi-magda-mcp-0.1.0.tgz
magda-mcp-server doctor --json
magda-mcp-server config
~~~

需要在 MAGDA Settings → Connections → MCP 开启 MCP，并给 MAGDA-MCP/<宿主名> 授予所需 scope。此 Release 提供 npm 可安装的 tarball，不依赖 npm registry 发布。

## 验收范围

自动检查覆盖类型检查、ESLint、构建及 27 项测试；协议矩阵为九种上下游组合，每种都使用官方 SDK 客户端和真实 stdio 子进程，对全量 154 个工具验证通用转发，并检查资源和订阅。模拟响应的成功代表传输保真，不代表每个工具都执行过真实音乐业务。

Windows/MAGDA 实机检查包括完整 Schema 与 TSV 名称核对、所有固定资源、四个资源模板、三种下游协议、只读客户端拒写、授权客户端创建轨道、MIDI 音符、revision 冲突、幂等请求、资源失效通知、设备参数修改读回、自动化、Session 场景、播放/定位/停止、保存临时工程和异步渲染。结果见 live-acceptance-0.1.0.json。

权限验收记录另见 permission-acceptance-0.1.0.json。已验证首次客户端只读和配置撤权在重启后的生效行为。同进程 GUI 即时授权/撤权未验证：测试实例为隐藏窗口，Windows 自动化无法激活该窗口。本版不以诊断读取成功推断写权限。

发布包在仓库外临时目录安装，用官方 SDK 检查离线和真实 MAGDA 连接、156 个工具、状态、原生读取、资源、CLI 退出码与绝对路径配置。运行不依赖源码、.resource 或测试夹具；检查包内文件白名单、测试凭据及 stdout。随 Release 提供本地实机安装记录 package-acceptance-0.1.0.json、CI 独立安装记录 package-acceptance.json 和 SHA256SUMS。

## 限制

- 仅正式支持上述操作系统、架构和 MAGDA 版本；其他版本只读和诊断可用，变更被兼容性检查阻止。
- 硬件 MIDI、第三方插件和每个原生工具的实机业务路径未逐项执行；hardware-midi scope 未授予测试客户端。
- 代表性流程使用隔离配置和临时工程，工程与渲染输出不随包分发。
- MAGDA 有请求速率限制。拒绝返回原生错误；代理不会自动重放写入。
- 连接中断或取消等待后的变更可能返回 OUTCOME_UNKNOWN；先检查项目或作业结果。后台作业需调用 jobs.cancel 取消。
- 资源通知没有事件重放，恢复订阅后必须重读相关资源。
- macOS/Linux、更多 MAGDA 版本及复合编曲工具列入后续版本。
