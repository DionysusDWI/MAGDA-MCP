# 开发计划

## v0.1.0 里程碑

| 里程碑 | 交付与验收依据 |
|---|---|
| M0 工程基础 | 继承远端 main 与 MIT；TypeScript ESM、锁文件、检查命令、CI、调研归档 |
| M1 连接与契约 | Windows 版本识别、目录解析、实例选择、固定 PID、实机 154/8/4 完整契约 |
| M2 MCP 服务 | 原生工具与资源代理、两个管理工具、离线目录、双协议年代订阅、错误保真 |
| M3 验证与文档 | 九种协议组合、连接故障与取消、代表性 Windows 工作流、权限和安装说明 |
| M4 发布 | 仓库外 tarball 安装、校验值、验收记录、v0.1.0 标签与 GitHub Release |

依赖关系：M0 → M1 → M2 → M3 → M4。契约由实机采集冻结；协议矩阵使用独立模拟 MAGDA 服务和真实 stdio 子进程。里程碑以可构建提交记录，正式发布前重新运行完整检查和包验收。

## 后续版本

1. 编曲工作流：在原生工具之上添加有单独命名空间、可预览且可验证的复合操作。
2. macOS / Linux：实现对应进程版本读取，增加操作系统实机矩阵后再声明支持。
3. MAGDA 更多版本：按应用版本保存独立契约，明确兼容性策略及漂移验收。
4. 增加不同 MCP 宿主的实机安装与权限体验验证；首版验收使用官方 SDK 客户端。

后续能力不通过修改 v0.1.0 基线静默启用；每次扩展都需独立测试与版本说明。
